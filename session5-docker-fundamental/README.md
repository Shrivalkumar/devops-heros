# Docker Hello World Applications

This homework contains four independent web applications. Build and run any one
from the repository root using the command in that application's `README.md`.

| Folder | Technology | URL after running |
| --- | --- | --- |
| `nodejs-app` | Node.js / Express | http://localhost:3000 |
| `python-app` | Python / Flask | http://localhost:5000 |
| `java-app` | Java built-in HTTP server | http://localhost:8080 |
| `apache-app` | Apache HTTP Server | http://localhost:8081 |
